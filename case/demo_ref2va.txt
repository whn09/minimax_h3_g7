# A SYNTHETIC ref2va case, written only to make the commands in README.md runnable from a fresh
# clone. Every number in this repo's matrix was measured on a different prompt -- a customer's, which
# is not here and will not be -- so treat this file as a shape, not as a reproduction.
#
# WHAT CARRIES OVER FROM THE REAL PROMPT, because it is what the timings depend on:
#   * one static shot, 768p, 121 frames (5.04 s), seed 42;
#   * ~3.5 k characters of prompt (the real one was 3 337), because MiniMaxH3TextEncodingStage runs
#     Qwen3-VL over the whole string and its ~1.7 s is roughly linear in that length. A 200-character
#     prompt makes the floor look better than it is;
#   * one reference image, which VisualEncoding resizes to a 2048 short edge (~0.6 s);
#   * no spoken dialogue, so the audio branch has nothing to synthesise. Adding <d> tags does not
#     change the step count but does change what the DiT has to solve.
#
# THE FORMAT IS THE OFFICIAL ONE and it is documented even though the system that emits it is not:
# SGLang feeds this text to Qwen3-VL verbatim (presentation.py:109, no chat template, no rewriter),
# while MiniMax's own product first runs the input through H3-Context-IR, a hosted multi-stage
# rewriter that the release explicitly excludes. So whatever you send IS the IR, and a one-sentence
# prompt is an out-of-distribution input rather than a short one. ref2va takes SIX blank-line
# separated sections (VIDEO_PROMPT_WRITING_GUIDE_ref_en.md sec. 1):
#     subject_definitions / summary / retention_analysis / detailed_description /
#     overall_soundscape / non_diegetic_music
# with every asset labelled (`<Subject N>` for reusable content, `<Picture N>` for a frame anchor),
# a bracketed task prefix on the summary, one of fully_preserved / partially_preserved /
# attribute_transfer / weak_reference per label in retention_analysis, and 350-500 English words of
# detailed_description. On-screen text stays in its source language inside double quotes; only
# dialogue and on-screen text are ever non-English. The full derivation, including four rules whose
# violation each matched one visible defect, is in minimax_h3_h100/PROMPT_IR.md.
#
# `\n` below is decoded to a real newline by sglang_case.py -- the file is one case per LINE and the
# format needs blank lines, so the two cannot both be literal. The trailing token is the reference
# image filename, resolved against refdir= (default /data/h3/ref). SUPPLY YOUR OWN demo_ref.jpg:
# a single frame of the subject and scene you want preserved. ref2va means "keep this subject and
# this scene", not "arrive at this frame" -- if your image is the END state of the action you are
# asking for, you want task fl2va with an explicit frame_index instead.
